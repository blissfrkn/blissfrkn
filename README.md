# Hi, I'm Furkan 👋

I'm a software developer with **4+ years of professional experience** on the product development team at [Entegra Bilişim](https://www.entegrabilisim.com). I work on integration-heavy business software and I'm also building **Cilt Bakımı Pro**, a privacy-conscious skincare companion for iOS and Android.

## Professional experience

### Entegra Bilişim — Software Developer

I'm part of the development team behind Entegra, a commerce integration platform that brings marketplace, ERP and accounting, e-Invoice and cargo operations together in one place.

- Developing and maintaining Windows desktop workflows with **C#, WPF and .NET Framework**
- Building marketplace, ERP, accounting, e-Invoice and cargo integration flows
- Working with **ASP.NET MVC, Entity Framework, React and JavaScript**
- Solving synchronization, order, stock, invoicing and operational workflow problems across connected systems

## Currently building

### Cilt Bakımı Pro

A mobile companion for organizing skincare routines, following progress and making product discovery easier. The product is being prepared for release with privacy, clear health boundaries and secure infrastructure as core engineering requirements.

- Building the mobile application with **Flutter and Dart**
- Designing APIs and background jobs with **Supabase, PostgreSQL and Cloudflare Workers**
- Preparing subscriptions, CI/CD and production operations
- Exploring sustainable, self-hostable infrastructure for growing products
